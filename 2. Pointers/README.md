# Introduction to Pointers

A **pointer** is a variable that stores the memory address of another variable instead of storing the actual value directly.

---

## Core Concepts

### 1. Dereferencing Pointer
Dereferencing a pointer means accessing or modifying the value stored at the memory address that the pointer points to.

### 2. Null Pointer
A **null pointer** is a pointer that does not point to any valid memory location. It is assigned the special value `NULL`.

---

## Passing Arguments

* **Pass by Value:** When the parameter is a copy of the actual argument variable in memory.
* **Pass by Reference:** When we pass the reference of the argument to the function:
  1. **Pointers**
  2. **Reference Variables**
